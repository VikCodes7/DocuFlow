# DocuFlow

Offline, privacy-first image and PDF tools for Windows and macOS.

> **Your files. Your device. Your privacy.**

The full product and technical plan is in
[DocuFlow_Technical_Foundation_v3.md](DocuFlow_Technical_Foundation_v3.md).

## Stack

Tauri 2 · React 19 · TypeScript · Vite · Tailwind CSS · Rust.
Processing lives in the `docuflow-core` crate; `src-tauri` is a thin app layer.

## Prerequisites

| Tool | Notes |
|---|---|
| Rust (stable) | `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs \| sh` |
| Node.js 22+ | npm is used as the package manager |
| macOS | Xcode Command Line Tools (`xcode-select --install`) |
| Windows | Microsoft C++ Build Tools ("Desktop development with C++") and WebView2 (preinstalled on Windows 11) |
| NASM | Needed once image encoding (`mozjpeg`) is added: `brew install nasm` / `winget install NASM.NASM` |

## Getting started

```sh
npm install
npm run tauri dev      # launches the desktop app with hot reload
```

## Common commands

| Command | What it does |
|---|---|
| `npm run tauri dev` | Run the app in development mode |
| `npm run tauri build` | Build an installer for the current OS |
| `npm run tauri build -- --target universal-apple-darwin` | macOS universal build (Apple Silicon + Intel) |
| `cargo test --workspace` | Rust tests; also regenerates `src/bindings/index.ts` |
| `npm run bindings` | Regenerate TypeScript bindings only |
| `npm test` | Frontend tests (Vitest, mocked IPC) |
| `npm run lint` / `npm run typecheck` | ESLint / TypeScript |
| `cargo clippy --workspace --all-targets -- -D warnings` | Rust lint |
| `cargo deny check` | License, advisory and source policy ([deny.toml](deny.toml)); needs `cargo install cargo-deny` |
| `cargo about generate about.hbs -o THIRD_PARTY_NOTICES_RUST.html` | Rust license notices; needs `cargo install cargo-about` |
| `npm run licenses:npm` | Frontend license allowlist check |

## Project layout

```text
crates/docuflow-core/   Image & PDF processing (no Tauri dependency)
src-tauri/              Tauri app: commands, jobs, access control, history, logging
src/                    React frontend
  bindings/             Generated by tauri-specta. Do not edit.
  features/             One folder per screen
  i18n/                 All UI text
tests/fixtures/         Shared image/PDF test corpus
```

## Rules of the road

- **Call Rust only through `src/bindings`.** Add a command in `src-tauri/src/commands`,
  register it in `specta_builder()` (`src-tauri/src/lib.rs`), then run `npm run bindings`.
- **Every file path goes through the allowed-path registry** (`src-tauri/src/access`).
  The frontend has no file system permissions.
- **Write outputs with `output::write_new_file`.** It never overwrites and never leaves partial files.
- **Never log file names, paths or contents.** Use `logging::file_ref(path)`.
- **No hard-coded UI text.** Add strings to `src/i18n/en.json`.
- **New dependencies must use a permissive license.** CI rejects GPL, LGPL and AGPL.
